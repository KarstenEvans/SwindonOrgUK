# Generated / published site output

This directory is intended for the rendered static Swindon.org.uk site used by the Cloudflare Pages deployment.

The canonical source for principal pages is the Markdown specification under `pages/`, combined with the shared rules in `docs/` and declared data/assets.

Do not make an important change only in generated `.htm` and leave the Markdown source stale. If an emergency/manual HTML fix is made, reconcile it back into the canonical source afterwards.
