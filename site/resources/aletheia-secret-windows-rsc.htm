Best first question: hardware or Windows?

If the PC still boots from a mechanical HDD, an SSD can make a much larger difference than hours of service tweaking. Microsoft describes SSDs as faster than HDDs and notes that storage speed materially affects PC responsiveness.

If the machine has only 4 GB RAM, check whether it can take 8 GB. Microsoft currently recommends 8 GB for longer-term everyday use, while 16 GB or more can suit heavier work.

Capacity correction: for SSDs we mean GB, not MB. A practical budget range is usually 240/250/256 GB minimum, with 480/500/512 GB a nicer default if the machine supports it.

💾 2.5-inch SATA SSDs

Common in older laptops and desktops. Check the exact model first. A 480/500 GB SATA SSD is a sensible target; 240/256 GB can be enough for a very light machine.

🧠 RAM upgrade

Do not buy RAM from the label “i5 laptop” or “HP Pavilion” alone. Check the full model/product number, slot count, soldered memory, DDR generation and maximum supported capacity.

📀 Keep the old HDD

On some older laptops, the original hard disk can move into the optical/DVD bay after an SSD goes into the primary bay. The linked 9.5 mm caddy is an example for the HDD/SSD. If you still want to use the removed laptop DVD drive, a separate SATA-to-USB optical-drive enclosure can turn it into an external USB drive. Caddies come in different heights, so measure/check the service manual first.

🧰 Small useful extras

  • USB-to-SATA enclosure/adapter for cloning or recovering an old drive.
  • 8–32 GB USB flash drive for Windows recovery/install media.
  • Small precision screwdriver set.
  • Anti-static strap if working inside a desktop/laptop.
  • External backup drive if the old HDD is the only copy of personal data.

🧬 Put Registry Backup back

Microsoft stopped automatically populating Windows\System32\config\RegBack starting with Windows 10 version 1803. Microsoft documents EnablePeriodicBackup=1 to re-enable the legacy periodic backup behaviour.

ENABLE REGBACK .REG UNDO .REG

Read the file before importing it. Restart Windows after enabling. The Secret Windows card explains what the setting changes.

🚦 Keep Windows Update away from drivers

On supported Windows editions, Microsoft documents the policy Do not include drivers with Windows Updates. This can reduce the chance of a quality update replacing a working vendor driver.

EXCLUDE WU DRIVERS .REG UNDO .REG

This is not a promise that every hardware-related package will never change. Firmware and drivers bundled inside other update types can behave differently.
